🔐 PyPassword Generator

PyPassword Generator is a Python program that creates strong, random passwords based on user preferences. The user can choose how many letters, symbols, and numbers to include in the password.

The project includes both an easy version (ordered password) and a hard version (fully randomized password).

🎯 Objective

To generate secure passwords using randomness while practicing Python fundamentals such as loops, lists, and the random module.

🧠 How the Program Works

The program welcomes the user.

The user specifies:

Number of letters

Number of symbols

Number of numbers

The program randomly selects characters based on the input.

Two password generation methods are demonstrated:

Easy Version – characters are added in order (letters → symbols → numbers)

Hard Version – characters are shuffled for better security

🔑 Character Sets Used

Letters: Uppercase and lowercase (A–Z, a–z)

Numbers: 0–9

Symbols: ! # $ % & ( ) * +
